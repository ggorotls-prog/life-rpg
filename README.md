# 라이프 RPG (life-rpg)

6대 기록(일·관계·재정·건강·지성·영성)만 하면 캐릭터가 자동으로 크는 앱(2026-11-12 시작, 룡 혼자 씀). **1단계 = 보여 주기만**: 기록은 기존 기록 앱에서 하고, 이 앱은 읽어서 계산만 한다. 룡이 캐릭터를 위해 입력·설정하는 것 0개.

- 설계: `설계안.md`(2판 + 룡 답) · 조사 원문: `조사\`(8개) · SQL: `sql\`
- 규칙(화면 `index.html` 맨 위에도 적음): 영역마다 기록한 날 = 10 EXP, 재정·관계는 하루 25·한 주 70까지(주 3일이면 가득). 영역 레벨은 다음 레벨까지 `10×(레벨+1)`. 캐릭터 = (영역 레벨 합 + 가장 낮은 영역×2) ÷ (영역 수+2) → 고르게 클수록 빨리. 한 번 닿은 레벨은 안 내려감(`rpg_players.peaks`). 벌칙·끊김 표시 없음. 지성은 기록 통로가 생길 때까지 「준비 중」.
- 세는 것(`rpg_days`): 일 = 내가 끝낸 할 일(Claude ⚡·🛠 줄 빼고) / 건강 = 기상·취침·운동·식단·오운완 / 영성 = 영성 기록 모든 종류 / 재정 = 내가 볼 수 있는 장부(아내가 적은 가정 장부 포함) / 관계 = 통화·메모 + 카톡 1:1.
- 화면: 캐릭터 레벨 · 오늘 나아간 것(일간 보고) · 능력치 6칸 · 최근 4주 모양(6각형 + 그 전 4주 비교) · 시즌(13주, 고른 주) · 누적 배지. 오랜만에 열면 「그동안 쌓인 것」, 레벨 오르면 알림.
- 홈 화면 위젯(2026-11-12 룡 「잠금화면 앞보다 위젯으로 먼저」): 맨 위 Lv·막대·오늘 n칸·🏠 👛 ⛪ 버튼(앱의 그 창), 아래 오늘 일정 + 할 일 목록(TodayService, 업무 기록 캘린더 위젯과 같은 나누기). 내 할 일 동그라미 = 완료 확인 창(WidgetAction), 요청받은 일 = 업무 기록 앱, 일정 = 구글 캘린더. 업무 기록 캘린더 위젯 자리를 대신하려는 것. 밤 9시 30분 「오늘 나아간 것」 알림(21:30~21:45).
- 서버: 슈파베이스 「룡룡룡」 `rpg_sessions`·`rpg_players`(잠김), 함수 `rpg_login`·`rpg_logout`·`rpg_days`·`rpg_save_peaks`. 기존 표는 읽기만.
- 로그인 = 업무 기록 아이디(관계·재정 기록과 같은 방식). 열쇠는 폰에, 365일.
- 빌드: GitHub Actions → `app/life-rpg.apk` + `app/version.json`(앱이 보고 스스로 업데이트). 서명은 기록 앱 공용 열쇠 `record`.
- 받기: https://ggorotls-prog.github.io/life-rpg/
- **마을(2단계, 2026-11-12)**: 첫 화면. 맨 위 아이콘 3개(집·지갑·아빠 집)로 바로 기록하고, 그 아래 **「오늘」 = 폰 캘린더 일정 + 내 할 일**(업무 기록 캘린더 위젯과 같은 나누기: 요청받은 일 → 지난 할 일·하루 종일·시간 순, 지금 줄 → 적어 둔 일 접힘). 할 일 동그라미 = 완료(+EXP), 요청받은 일·새 할 일은 업무 기록 앱으로. 일정을 누르면 구글 캘린더. 「룡 - 」처럼 남의 이름표 일정은 흐리게. 기록은 기존 앱과 같은 표에 쌓인다(`sql6-11-12 마을 기록.sql`). 2026-11-12 룡: 「퀘스트를 따로 두지 말고 기본 화면이 일정과 할 일」.
  - 🏠 집 = 건강 기록 `life_days`: 일어났어요(컨디션 😫😐😄, 어젯밤 잔 시각이 없으면 같이) · 잘게요. 규칙은 life_wake·life_bed와 같음(새벽 4시 경계). 폰 잠금은 안 함.
  - 👛 지갑 = 재정 기록 앱의 빠른 기록 창(`app.faithbudget/.QuickActivity`, 재정 위젯 − 지출과 똑같은 창: 금액 → 가정/기업 → 항목 → 저장)을 연다(2026-11-12 룡 「재정기록 위젯이랑 동일하게」). 재정 기록 앱이 없을 때만 자체 창(`rpg_fin_add`).
  - 할 일 = 업무 기록 `work_tasks`: 내가 나에게 준 할 일만 여기서 완료(done_at 오늘).
  - ⛪ 아빠 집 = 영성 기록 앱(app.personalrecord)을 연다. 대신 쓰지 않는다. 오늘 한 것(묵상·감사·칭찬·SOC·일기)만 보여 줌.
  - 기록하면 바로 「+EXP」가 뜨고 상태창이 새로 계산된다.
- 다음(룡 구상): 잠금화면 「앞」에 마을 띄우기, 식탁(식사 사진), 기도 시간 재기·통독 체크(영성은 묵상 = 했는지, 기도 = 시간, 통독 = 말씀 체크표).
