# 라이프 RPG (life-rpg)

6대 기록(일·관계·재정·건강·지성·영성)만 하면 캐릭터가 자동으로 크는 앱(2026-11-12 시작, 룡 혼자 씀). **1단계 = 보여 주기만**: 기록은 기존 기록 앱에서 하고, 이 앱은 읽어서 계산만 한다. 룡이 캐릭터를 위해 입력·설정하는 것 0개.

- 설계: `설계안.md`(2판 + 룡 답) · 조사 원문: `조사\`(8개) · SQL: `sql\`
- 규칙(화면 `index.html` 맨 위에도 적음): 영역마다 기록한 날 = 10 EXP, 재정·관계는 하루 25·한 주 70까지(주 3일이면 가득). 영역 레벨은 다음 레벨까지 `10×(레벨+1)`. 캐릭터 = (영역 레벨 합 + 가장 낮은 영역×2) ÷ (영역 수+2) → 고르게 클수록 빨리. 한 번 닿은 레벨은 안 내려감(`rpg_players.peaks`). 벌칙·끊김 표시 없음. 지성은 기록 통로가 생길 때까지 「준비 중」.
- 세는 것(`rpg_days`): 일 = 내가 끝낸 할 일(Claude ⚡·🛠 줄 빼고) / 건강 = 기상·취침·운동·식단·오운완 / 영성 = 영성 기록 모든 종류 / 재정 = 내가 적은 장부 기록만(2026-11-16 룡 「내 건 내 거, 와이프 건 와이프 거」, 적은 사람 칸이 빈 옛 기록은 나만 있는 장부일 때만) / 관계 = 통화·메모 + 카톡 1:1.
- 화면: 캐릭터 레벨 · 오늘 나아간 것(일간 보고) · 능력치 6칸 · 최근 4주 모양(6각형 + 그 전 4주 비교) · 시즌(13주, 고른 주) · 누적 배지. 오랜만에 열면 「그동안 쌓인 것」, 레벨 오르면 알림.
- 홈 화면 위젯(2026-11-12 룡 「잠금화면 앞보다 위젯으로 먼저」): 맨 위 Lv·막대·오늘 n칸·🏠 👛 ⛪ 버튼(앱의 그 창), 아래 오늘 일정 + 할 일 목록(TodayService, 업무 기록 캘린더 위젯과 같은 나누기). 내 할 일 동그라미 = 완료 확인 창(WidgetAction), 요청받은 일 = 업무 기록 앱, 일정 = 구글 캘린더. 목록 위에 업무 기록 위젯의 핵심 줄 「요청 n · 확인 n · 맡기기 · ＋ 할 일」(순서 2026-11-12 룡)(업무 기록 앱의 그 창을 그대로 연다: QuickAddActivity / MainActivity assign / 앱). 확인 = 내가 맡긴 일 중 상대가 「다 했어요」한 것(`rpg_home.to_check`). 마을 「오늘」 카드에도 같은 줄. 업무 기록 캘린더 위젯 자리를 대신하려는 것. 밤 9시 30분 「오늘 나아간 것」 알림(21:30~21:45).
- 서버: 슈파베이스 「룡룡룡」 `rpg_sessions`·`rpg_players`(잠김), 함수 `rpg_login`·`rpg_logout`·`rpg_days`·`rpg_save_peaks`. 기존 표는 읽기만.
- 로그인 = 업무 기록 아이디(관계·재정 기록과 같은 방식). 열쇠는 폰에, 365일.
- 빌드: GitHub Actions → `app/life-rpg.apk` + `app/version.json`(앱이 보고 스스로 업데이트). 서명은 기록 앱 공용 열쇠 `record`. 기록 앱 폰 기능은 원본 한 벌을 빌드 때 받아 쓴다: 건강 기록 `life-room/android/healthkit`(취침 잠금·화면·알림), 재정 기록 `faith-budget/android/finkit`(화면·빠른 기록 창·위젯), 업무 기록 `greenjui-calls/android/workkit`(화면·적기 창·위젯 둘·알림·녹음), 영성 기록 `personal-record/android/spiritkit`(화면·적기 창·위젯·묵상 알림·7분 타이머), 관계 기록 `relation-record/android/relkit`(화면·통화 모으기·묻기 창) → `android/ext/`(저장소에 안 올림). 업무·영성 저장소는 비공개라 읽기 전용 배포 키(비밀값 `KIT_WORK_KEY`·`KIT_SPIRIT_KEY`, 2026-11-16 룡 OK)로 받는다. 업무 기록 바로 오는 알림 열쇠는 `FIREBASE_API_KEY`. 시험할 때는 Run workflow에서 원본 가지(`work_ref`·`spirit_ref`·`rel_ref`)를 고를 수 있다. 그 원본을 고쳐 push하면 **그 자리에서 RPG 빌드도 부른다**: `gh workflow run android.yml -R ggorotls-prog/life-rpg`(PC gh 로그인으로. 열쇠 `RPG_DISPATCH`는 안 만듦 — 만들면 기록 앱 빌드 끝에서 저절로 부름. 2026-11-16 룡 「바로 실시간」). 15분 점검(`schedule`)은 예비(`app/kits.json` = 지난 판이 쓴 원본). **고칠 곳은 늘 원본**: 기록 앱 화면·폰 기능의 문제는 RPG에서 봤든 단독 앱에서 봤든 그 기록 앱 저장소(웹 화면·`healthkit`·`finkit`)에서 고친다 → 웹 화면은 두 앱에 바로, 폰 기능은 두 앱 새 버전으로 같이 들어간다.
